Topic 8 of the assignment

Context

What is a call center?

  • A call center is the point of contact between a company and its customers by phone.
  • Core components: IVR (menus driven by DTMF), queues (callers wait for agents), agents (operators).
  • Traditional solutions: proprietary platforms (Genesys, Cisco, Avaya) — expensive, per-agent licensing, complex.
  • Open source alternative: Asterisk — the world’s most popular open-source communications project. Native support for IVR, queues, agents.

State of the art

Call centers evolution

  • Traditional (TDM): ACD on circuit-switched networks, rigid and vendor-locked.
  • IP era (2000s): SIP-based contact centers — flexibility, agents anywhere.
  • Cloud (2010s+): CCaaS (Genesys, Amazon Connect), paid per agent — omnichannel + AI.

Technology

Asterisk core

Architecture: core + modules + channels + dialplan.

/etc/asterisk/
├└└ pjsip.conf       → SIP accounts (PJSIP objects: transport, auth, AoR, endpoint)
├└└ extensions.conf → dialplan (contexts, exten, priorities, IVR, queueing)
├└└ queues.conf      → call queues (strategies, timeouts, announcements)
├└└ voicemail.conf   → voicemail boxes

Key point: every call goes through the dialplan, which decides who can call, where the call goes, who answers, what happened (CDR).

Technology

Dialplan + IVR

[ivr-main]
exten => s,1,Answer()
 same => n,Progress()                  ; early media
 same => n,Set(SELECTED_QUEUE=sales)   ; default destination
 same => n,Background(cc-welcome)      ; our recording: press 1, 2 or 0
 same => n,WaitExten(5)

exten => 1,1,Set(SELECTED_QUEUE=sales)   → Queue(${SELECTED_QUEUE},,,,120)
exten => 2,1,Set(SELECTED_QUEUE=support) → Queue(${SELECTED_QUEUE},,,,120)

Design: instead of one dialplan branch per menu option, the IVR stores the destination in a channel variable and sends all calls to a single Queue() context — adding a new department means changing one line.

Opinion & contribution

Our own take on Asterisk

  • Positive: PJSIP + dialplan + app_queue form a complete, zero-licence call center — many modules work together out of the box.
  • Negative: steep learning curve, no default GUI, dialplan typos silently change flows — we configured everything by hand to understand it.
  • Our contribution: unified IVR→queue design via channel variable; dynamic agent login with *88/*89; original eSpeak-ng prompts; reproducible lab (SIPp + CDR + Wireshark) shipped with the docs.
